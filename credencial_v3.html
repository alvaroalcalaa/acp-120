Descripción

El Administrador Profesional Certificado de Jira para la Nube de Atlassian (ACP-JCA) gestiona, personaliza y configura Jira desde la interfaz de usuario, garantizando el rendimiento, la escalabilidad y la facilidad de gestión diaria del producto. El ACP-JCA posee las habilidades necesarias para optimizar Jira Cloud para cualquier equipo de desarrollo o de negocio.
